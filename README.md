# روان‌ت — رو (تست Vercel)

## دیپلوی در ۳۰ ثانیه
1. https://vercel.com/new
2. Import این ریپو: pooyaazadiwork-cell/ravanet-ro-vercel
3. Environment Variables:
   - RO_LLM_API_KEY = کلید DeepSeek
   - RO_LLM_BASE_URL = https://api.deepseek.com
   - RO_LLM_MODEL = deepseek-flash
4. Deploy
5. روی لینک باز شو و چت کن
